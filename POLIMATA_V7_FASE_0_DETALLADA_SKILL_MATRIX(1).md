# PROYECTO POLÍMATA V7.0
## FASE 0 — Aprender a aprender, pensar, investigar y comunicar
### Manual ejecutable detallado de 16 semanas + compatibilidad con `libro-esencial`

**Versión:** 2.0  
**Estado:** propuesta ejecutable para integrar antes del Año 1 de `PROYECTO POLÍMATA V6.0`  
**Duración:** 16 semanas  
**Carga objetivo:** 6–8 horas/semana + repasos espaciados breves  
**Propósito:** construir las capacidades necesarias para aprovechar el canon de 170 obras sin convertir el proyecto en lectura pasiva, acumulación de notas o dependencia de IA.

---

# 1. PRINCIPIO GENERAL

La Fase 0 no es una bibliografía adicional que deba “terminarse” antes de empezar Polímata. Es un **laboratorio de adquisición de conocimiento**.

Su finalidad es que, al terminar, el estudiante pueda:

1. planificar qué necesita aprender;
2. activar conocimientos previos;
3. leer según el tipo de disciplina;
4. recuperar sin mirar;
5. detectar errores y omisiones;
6. calibrar su confianza;
7. reconstruir argumentos;
8. evaluar evidencia y fuentes;
9. interpretar datos y afirmaciones causales;
10. construir modelos;
11. transferir ideas a problemas nuevos;
12. escribir para pensar;
13. explicar para diferentes audiencias;
14. representar justamente posiciones rivales;
15. debatir sin caricaturizar;
16. usar IA como tutor, auditor y adversario, no como sustituto cognitivo;
17. mantener memoria a largo plazo mediante recuperación espaciada;
18. integrar lo aprendido al `Question Ledger`, grafo y FSRS.

La regla operativa es:

> **PRIMERO esfuerzo propio → DESPUÉS auditoría externa/IA.**

# 2. CÓMO INTERPRETAR LA COMPATIBILIDAD CON `libro-esencial`

La Skill actual declara:

- está diseñada para **libros PDF de no ficción**;
- produce una edición reducida y ruta de estudio;
- no sustituye la lectura ni el pensamiento;
- distingue modos disciplinares;
- para matemática/lógica/programación trabaja por dependencias + ejercicios y no por porcentaje;
- literatura normalmente requiere 80–100 %.

Por tanto, en este documento se usan cuatro etiquetas.

## ✅ SÍ — USO DIRECTO

La fuente es un **libro o monografía PDF de no ficción** y encaja directamente con la Skill actual.

Se puede ejecutar:

`Edition Gate → Prerequisite Gate → mapa → ruta → selección → verificación → prelectura → lectura → postlectura → examen`.

## 🟡 SÍ — PERO EN MODO RUTA, NO “RESUMEN”

La fuente es un **manual, textbook, handbook o gran informe**.

La Skill puede usarse, pero el objetivo debe ser:

- localizar capítulos necesarios;
- conservar dependencias;
- asignar ejercicios;
- construir ruta;
- NO producir simplemente “X % de páginas”.

Ejemplos: estadística, lógica formal, informes extensos.

## 🟠 NO DIRECTAMENTE — REQUIERE ADAPTADOR `PAPER_ESSAY`

La fuente es:

- artículo científico;
- ensayo académico corto;
- paper experimental;
- metaanálisis;
- capítulo independiente corto.

La Skill actual dice que es para libros PDF. Por eso **no debe usarse sin modificación**.

Regla futura recomendada:

> Si un artículo es razonablemente corto, se lee completo. La IA crea mapa, guía de lectura, auditoría y examen, pero no intenta reducirlo.

## 🔴 NO — USAR OTRO FLUJO

La fuente es principalmente:

- sitio web;
- módulo interactivo;
- conjunto de páginas web;
- ejercicio;
- base de datos;
- video;
- material no lineal.

La Skill `libro-esencial` no es la herramienta adecuada.

# 4. ARQUITECTURA COGNITIVA DE CADA SEMANA

Cada semana usa el siguiente ciclo.

## Fase A — Orientación

Antes de leer:

1. ¿qué problema intenta resolver esta semana?
2. ¿qué creo ya sobre el tema?
3. ¿qué podría estar equivocado?
4. ¿qué conceptos previos necesito?
5. ¿qué espero poder hacer al finalizar?

Registrar:

```text
PRETEST
confianza_inicial: __/100
respuesta_inicial:
dudas:
```

## Fase B — Adquisición

Leer únicamente el material prescrito.

Durante la lectura:

- notas mínimas;
- preguntas;
- tesis;
- evidencia;
- estructura;
- dificultades.

Evitar transcribir el libro.

## Fase C — Recuperación cerrada

Cerrar todo.

Producir:

- free recall;
- esquema;
- conceptos;
- ejemplos;
- dudas.

## Fase D — Auditoría

Comparar contra la fuente.

Clasificar:

```text
DOMINIO
ERROR
OMISIÓN
DISTORSIÓN
CONFUSIÓN
CONEXIÓN_NO_JUSTIFICADA
```

## Fase E — Rescate

Sólo volver a las zonas deficientes.

## Fase F — Elaboración

Explicar:

- qué significa;
- por qué;
- cómo se relaciona;
- ejemplo;
- contraejemplo;
- límite.

## Fase G — Transferencia

Resolver algo que **no apareció exactamente en el material**.

## Fase H — Producción

Crear un producto:

- argumento;
- ensayo;
- explicación;
- mapa;
- experimento;
- análisis;
- debate.

## Fase I — Examen

Sin notas ni IA.

## Fase J — Calibración

Comparar:

```text
resultado_predicho
resultado_real
error_de_calibración
```

## Fase K — Memoria

Sólo después del dominio:

- FSRS;
- grafo;
- preguntas de reconstrucción;
- revisión a 7/30/90 días.

# 5. SEMANA 1 — QUÉ SIGNIFICA APRENDER

## 5.1 Meta

Construir una concepción científicamente defendible del aprendizaje.

No debes terminar la semana pensando:

> “aprender = leer y entender”.

Debes terminar distinguiendo:

```text
exposición
familiaridad
comprensión momentánea
recuerdo
retención
transferencia
dominio
```

## 5.2 Preguntas guía

1. ¿Qué diferencia existe entre rendimiento durante el estudio y aprendizaje duradero?
2. ¿Por qué algo puede sentirse fácil y olvidarse rápidamente?
3. ¿Qué función cumple el conocimiento previo?
4. ¿Qué limitaciones tiene la memoria de trabajo?
5. ¿Qué técnicas de estudio cuentan con mejor respaldo?
6. ¿Por qué subrayar o releer puede producir sensación de dominio sin garantizarlo?

# 32. CONCLUSIÓN OPERATIVA

## ¿Puedes usar tu Skill en la Fase 0?

**Sí, ampliamente, pero no para todo.**

La versión actual es adecuada para:

- libros;
- monografías;
- filosofía;
- ciencia de formato libro;
- ciencias sociales;
- manuales con ajuste;
- textbooks con ajuste por dependencias.

No debe aplicarse sin adaptación a:

- papers;
- metaanálisis;
- ensayos cortos;
- módulos web.

La regla de calidad es:

> **si el documento corto contiene una cadena argumental o experimental completa, conservarla completa suele ser mejor que reducirla.**

La función de la IA en esos casos no es recortar, sino:

> **orientar → preguntar → auditar → poner a prueba → ayudar a transferir.**

# 34. NOTA FINAL DE DISEÑO

La Fase 0 debe probarse como un sistema.

Antes de seguir añadiendo recursos:

1. ejecutar las 16 semanas;
2. medir dificultad y tiempo;
3. identificar redundancias;
4. medir retención y transferencia;
5. verificar qué partes de `libro-esencial` funcionan;
6. diseñar adaptadores sólo donde el benchmark demuestre necesidad.

Esto mantiene la filosofía de Polímata:

> **más rigor por unidad de lectura, no más volumen por inercia.**
